## Prose, links and inline semantics

A paragraph of ordinary Article prose, long enough to wrap at least twice inside the 768 px lined rail so the 16/28 measure can be judged against the reference rather than against a single line. It carries an [internal link](/blog/understanding-cache-components), an [external link](https://nextjs.org/docs/app/api-reference/directives/use-cache), a same-Article link to [the tables section](#tables), **strong text**, _emphasis_, ~~struck-through text~~ and `inlineCode` so the inline vocabulary sits in one place.

Press <Kbd>⌘</Kbd> <Kbd>K</Kbd> to open the command menu. Inline `Kbd` has to sit on the prose baseline without pushing the line box, which is the whole reason it is worth looking at inside a paragraph rather than on its own.

## Code

A plain block with no title, which is where the reference floats its copy control over the code rather than giving it a row:

```ts
export const revalidate = 3600;

export const load = async (slug) => {
  const article = await findArticle(slug);
  return article ?? notFound();
};
```

A titled block with line numbers starting at 12:

```tsx title="src/app/blog/[slug]/page.tsx" lineNumbers=12
export default async function ArticlePage({ params }) {
  const article = await resolveArticle(params);

  return <ArticleView article={article} />;
}
```

### Twoslash

Hover a token to read its inferred type:

```ts twoslash
const headings = ["Prose", "Lists", "Code"];

const bySlug = new Map(headings.map((text) => [text.toLowerCase(), text]));
//    ^?

const first = bySlug.get("prose");
```

An expected error, which is the other Twoslash state the language allows:

```ts twoslash
// @errors: 2345
const toDepth = (value: 2 | 3 | 4): number => value;

toDepth(7);
```

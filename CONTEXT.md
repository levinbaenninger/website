# Personal Website

This context describes the visitor-facing areas and concepts of Levin's personal website.

## Language

**Portfolio**: The area that presents Levin's background and work, including about, experience, education, projects, achievements, bookmarks, and social profiles.

**GitHub repository**: The public GitHub repository associated with a portfolio project. _Avoid_: Source repository, source URL

**Live site**: The publicly accessible running version of a portfolio project. _Avoid_: Demo, deployment

**Blog**: The area where visitors discover and read Levin's published articles.

**Article**: A piece of authored content for the Blog, in either draft or published state. _Avoid_: Blog post, post

**Article source bundle**: The authored source unit that groups an Article's content with the local assets it owns.

**Draft**: The Article state in which its content is not available to Blog visitors.

**Published**: The Article state in which its content is available to Blog visitors.

**Cover image**: The required decorative image that visually represents an Article within the Blog. It is not the Article's Open Graph image. _Avoid_: Social image

**Tag**: A controlled label used to group related Articles in the Blog. _Avoid_: Category

**Tag filter**: A single selected Tag that narrows the Blog catalog to Articles carrying that Tag. When combined with an Article search query, an Article must satisfy both.

**Tag count**: The number shown for a Tag filter. It counts all catalog Articles when Article search is idle and only query-matching Articles while a query is active, independently of the selected Tag filter.

**Article search**: The visitor-facing search across visible Article titles, Tag labels, descriptions, headings, and body text. Results are ordered by relevance and explain a match with visible highlighting or a matching excerpt.

**Catalog discovery state**: The current Article search query and Tag filter. When both are present, an Article must satisfy both.
